Park what Claude left unfinished. Pick it up exactly where it stopped.

Baton is a desktop app for people who work with Claude Code. It turns pending work into tasks with the agent’s own handoff notes, keeps your pull requests and stacks in view, and tells you the moment Claude needs an answer.

Download Baton Free for macOS, Windows and Linux All downloads

Uses the Claude Code and GitHub CLI logins you already have. Nothing to sign up for.

Works with Claude Code in the terminal and in VS Code, the GitHub CLI, and runs on macOS, Windows and Linux.

See it in 51 seconds

Everything between “Claude, do this” and “merged”

Park work with a real handoff

Type /task in any Claude Code session. Claude writes down where things stand, what’s next, which files and branches matter, and what’s still open, and files it in Baton linked to that session.

  • Link a task to several sessions and pull requests
  • Open the session again in VS Code or your terminal with one click
  • The conversation is saved with the task, even if the session is deleted

Your pull requests, stacks included

Baton reads your open pull requests and the ones waiting on your review through the GitHub CLI. Stacked PRs are grouped bottom to top, and a stack only counts as ready when every PR in it is.

  • Ready to merge and to address counters
  • Checks, approvals, conflicts and open threads on every PR
  • Filter review requests by author and hide drafts

Know the moment Claude needs you

Get a notification when Claude asks a question, waits for permission, has a plan for you to approve, or finishes a long run. The same inbox collects new comments, review requests, failing checks and PRs that just became ready.

  • Unread count on the app icon
  • Choose exactly which events notify you, and mute repos or PRs
  • Answer from Baton, or jump straight to the session

Read the whole review without the browser

Each pull request shows its description, review threads with file and line, reviews and comments, rendered the way GitHub renders them. Filter to what’s still unresolved.

Let Claude take the first pass

Describe what needs doing and start a new Claude Code session straight from the task. Baton writes the prompt from your notes, the handoff, and the linked PRs, and links the new session back to the task.

  • Plan first, ask before changes, or auto-accept edits
  • Opens in VS Code, Terminal or iTerm
  • A default project folder per task

Approve and merge when it’s green

See what’s still blocking a PR, pick the merge method your repo allows, or turn on auto-merge. Baton merges exactly the commit you looked at, and won’t merge the middle of a stack.

Message any session

Send Claude a follow-up from Baton. Closed sessions continue in the background and the reply lands back in the session.

Review requests in one tab

Everything waiting on you, grouped by stack, with an approve button and the author of each PR.

Stays on your machine

Baton reads Claude Code’s files on your computer and talks to GitHub through your own gh login. It has no server.

Fits the way you work

Resizable panes, keyboard shortcuts, and settings for what you want to hear about.

Set up in a minute

  1. Install Baton

    It finds your Claude Code sessions and your GitHub login on its own. If gh isn’t signed in, run gh auth login once.

  2. Add /task to Claude Code

    One click in Settings. Optionally add the hooks that tell Baton when a session is waiting for you.

  3. Hand off, then pick it back up

    Run /task when you stop. Baton keeps the handoff, watches the PRs, and brings you back when something moves.

Questions

Does Baton send my code or conversations anywhere?

No. It reads Claude Code’s session files on your computer (~/.claude) and stores tasks in ~/.baton. Pull request data comes from GitHub through your own gh login. There’s no Baton server or account.

Do I need to log in to anything?

No. Baton uses the Claude Code and GitHub CLI logins already on your machine. Opening a session runs claude exactly as you would.

Does it work with the Claude Code extension for VS Code?

Yes. Sessions from VS Code show up like any other, and Baton can open a session or start a new one in the VS Code Claude panel. Terminal and iTerm work too.

What does installing /task and the hooks change?

/task is a Claude Code skill added to ~/.claude/skills/task. The optional hooks are added to ~/.claude/settings.json; your other settings are kept, a backup is saved next to the file, and you can remove them from Settings.

Why does macOS say it can’t check Baton for malicious software?

Baton isn’t notarized by Apple yet. Right-click the app in Applications, choose Open, and confirm once. After that it opens normally.

How well does it work on Windows and Linux?

Tasks, sessions, pull requests and notifications work the same everywhere. Opening sessions uses Windows Terminal or PowerShell on Windows and your terminal emulator on Linux. These builds are new, so they’re marked beta; please report anything that doesn’t work.
